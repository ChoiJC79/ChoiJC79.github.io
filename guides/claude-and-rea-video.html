참고 영상을 샷 단위로 뜯어보는 4단계

읽는 데 14분스텝 4개섹션 7개2026-11-22 공개

이번 주 트렌드 · JuneYaooo/rea-video

홍보 영상을 만들 일이 생기면 「저 영상은 어떻게 찍었을까」부터 궁금합니다. 실제로 촬영했는지, AI로 만들었는지, 자막은 어떤 효과를 썼는지 하나하나 보기는 어렵습니다. rea-video는 영상 파일 하나를 받아 샷 단위로 쪼개고, 샷마다 실사인지 AI인지 코드로 만든 화면인지 판정한 뒤 다시 만드는 방법까지 정리해 주는 도구입니다. 클로드 코드에게 「설치하고 이 영상 분석해 줘」 한 줄만 하면 설치부터 리포트까지 알아서 진행합니다.

복사해서 바로 시작하는 프롬프트. 설치부터 첫 분석까지 AI에게 맡기기.

클로드 코드를 쓰는 분의 첫 메시지로 붙여넣으세요.

복사해서 바로 시작하는 프롬프트
역할: 이 컴퓨터에 rea-video를 설치하고 영상 한 편을 분석하는 담당
맥락: 저는 개발 경험이 적습니다. 참고하고 싶은 홍보 영상이 어떻게 만들어졌는지 알고 싶습니다.
작업: ① `ffmpeg -version` 과 `python3 --version` 으로 준비물을 보세요. ffmpeg가 없거나 파이썬이 3.10보다 낮으면 설치 방법만 알려 주고 멈추세요. ② https://github.com/JuneYaooo/rea-video 를 설치하세요. ③ 이 영상을 분석하세요: /여기에/영상파일/경로.mp4 ④ 리포트는 영어로 받고, 샷별 판정(실사·AI·코드·화면 녹화)을 한국어 표로 요약해 주세요.
제약: sudo 는 먼저 물어보세요. 원본 영상 파일은 옮기거나 지우지 마세요. 외부 영상 모델 키는 제가 주기 전에는 쓰지 마세요.
출력: 실행한 명령, report.html 경로, 샷 수, 샷별 판정 요약 표, 남은 오류
검증: report.html 파일이 실제로 있어야 하고 샷 수가 1개 이상이어야 합니다. 아니면 완료로 보고하지 말고 실패한 단계와 원인을 알려 주세요.

Quick Start

  • 공식 저장소: JuneYaooo/rea-video
  • 한 줄 정의: 영상을 샷마다 쪼개 실사·AI·3D·코드·화면 녹화 여부를 판정하고, 자막·편집·음향까지 분석해 다시 만드는 방법을 리포트로 내는 에이전트용 도구입니다.
  • 인기·만든 곳: 2026년 11월 22일 확인 기준 GitHub 스타 11,921개, 최신 판은 v0.1.0입니다. 2026년 10월 29일에 공개됐고 지금도 거의 매일 고치고 있습니다.
  • 라이선스: Apache-2.0. 개인 일과 기관 업무에 자유롭게 쓸 수 있습니다.
  • 필요한 환경: 클로드 코드(또는 Codex), ffmpeg, Python 3.10 이상
  • 비용: 도구는 무료입니다. 클로드 사용 요금은 따로 나갑니다. 영상 이해 모델(Gemini 등)을 연결하면 그 요금도 나갑니다.

클로드 코드 안에서 한 줄이면 됩니다.

클로드 코드 안에서 입력.

붙여넣을 글
https://github.com/JuneYaooo/rea-video 설치하고 이 영상 분석해 줘: /path/to/video.mp4
검증: 2026-11-22 기준 README(한국어판 포함)를 따랐습니다. 이 자료에서는 직접 영상을 분석해 보지 않았습니다.

STEP 1. 준비물 확인하기: 3분

이 단계에서는 영상을 다룰 프로그램이 있는지 봅니다.

터미널에서 ffmpeg -version 과 python3 --version 을 칩니다. 맥에서 ffmpeg가 없으면 brew install ffmpeg 로 설치합니다.

용어: ffmpeg는 영상을 자르고 프레임을 뽑는 무료 프로그램입니다. rea-video는 이걸로 영상을 장면별로 나눕니다.

STEP 2. 설치하기: 3분

이 단계에서는 에이전트에게 설치를 맡깁니다.

Quick Start의 한 줄을 그대로 쓰면 첫 분석 때 클로드가 알아서 설치합니다. 플러그인으로 미리 넣어 두고 싶다면 터미널에서 이렇게 합니다.

터미널에서 입력.

터미널에서 실행
claude plugin marketplace add JuneYaooo/rea-video
claude plugin install rea-video@rea-video

STEP 3. 영상 분석하기: 10~30분

이 단계에서는 영상 한 편을 넣고 결과를 기다립니다.

영상 길이와 샷 수에 따라 시간이 다릅니다. README 예시로는 70초짜리 제품 홍보 영상이 12샷, 165초 뮤직비디오가 86샷이었습니다. 분석하면 두 가지가 나옵니다.

결과물누가 읽나내용
report.html / PDF사람영상을 어떻게 만들었고 어떻게 다시 만들지 정리한 리포트
VIDEO.mdAI단계별로 나눈 분석. 이어서 질문하면 필요한 부분만 읽음

샷 판정 외에도 자막이 나오는 시간과 효과, 컷 속도, 음악이 AI 곡인지, 직접 준비해야 할 소재(화면 녹화, 제품 사진)까지 뽑아 줍니다.

  • ❌ 이렇게 말고: 유튜브 화질 낮은 재업로드 영상
  • ✅ 이렇게: 플랫폼에서 받은 원본에 가까운 파일. 압축을 여러 번 거치면 실사를 AI로 잘못 보는 비율이 올라갑니다

STEP 4. 결과로 기획하기: 10분

이 단계에서는 분석을 우리 영상 기획에 씁니다.

VIDEO.md 가 있는 상태에서 클로드에게 이어서 묻습니다. 「3번 샷처럼 찍으려면 장비가 뭐가 필요해?」「이 영상 구성 그대로 제천 관광 홍보 영상 콘티를 짜 줘」처럼 쓰면 됩니다.

자주 막히는 곳

  • 리포트가 중국어로 나옵니다: 리포트는 질문한 언어로 나오는데 중국어와 영어만 지원합니다. 영어로 받고 클로드에게 한국어 요약을 부탁하세요.
  • 실사 영상을 AI라고 판정합니다: 플랫폼 압축 때문에 생깁니다. 원본 파일을 쓰거나, 영상 모델(Gemini 등) 키를 에이전트에게 주면 정확도가 오릅니다.
  • 오래 걸립니다: 긴 영상은 앞 30초만 잘라서 먼저 돌려 보세요.

솔직히 한계

  • 리포트에 한국어가 없습니다. 판정 결과도 확률이라, 중요한 판단(저작권, AI 생성 여부 확인)에 근거로 쓰기는 이릅니다.
  • 판 번호가 0.1이고 매일 바뀌는 중이라, 이 글의 설명과 실제 화면이 다를 수 있습니다.
  • 남의 영상을 분석하는 것은 배우는 용도로 쓰고, 그대로 베껴 만드는 데 쓰면 저작권 문제가 생길 수 있습니다.
