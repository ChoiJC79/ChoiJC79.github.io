개념을 움직이는 그림 한 장으로 설명하는 4단계

읽는 데 15분스텝 4개섹션 7개2026-11-22 공개

이번 주 트렌드 · wheresryan22/anatomy

보고서나 칼럼에 「이 제도가 어떻게 돌아가는지」 그림 한 장 넣고 싶을 때가 있습니다. 파워포인트 도형으로 상자와 화살표를 그리면 시간은 걸리는데 읽는 사람은 잘 보지 않습니다. anatomy는 클로드 코드에 넣는 스킬입니다. 설명하고 싶은 개념을 말하면, 그 개념대로 움직이는 기계 같은 물건을 하나 지어내서 아이소메트릭(비스듬히 내려다본) 그림으로 그려 줍니다. 마우스를 올리면 부품이 움직이고, 화면의 숫자도 같은 계산에서 나옵니다. 결과물은 브라우저로 여는 HTML 파일 한 장입니다.

복사해서 바로 시작하는 프롬프트. 설치부터 첫 그림 한 장까지 AI에게 맡기기.

클로드 코드를 쓰는 분의 첫 메시지로 붙여넣으세요.

복사해서 바로 시작하는 프롬프트
역할: 이 컴퓨터의 클로드 코드에 anatomy 스킬을 설치하고 첫 설명 그림을 만들어 보는 담당
맥락: 저는 개발 경험이 적습니다. 업무 보고서와 칼럼에 넣을 「작동 원리 그림」을 만들고 싶습니다.
작업: ① `node -v` 로 Node.js 버전을 보세요. 20.10보다 낮거나 없으면 설치 방법만 알려 주고 멈추세요. ② `ls ~/.claude/skills/anatomy/SKILL.md` 로 이미 설치됐는지 보세요. 없으면 `npx skills add wheresryan22/anatomy -g -a claude-code` 를 실행하세요. ③ 설치되면 `/anatomy 지방세가 걷혀서 시·도와 시·군으로 나뉘는 흐름을 설명해 줘, 인터랙티브` 로 그림 한 장을 만들고 파일 경로를 알려 주세요.
제약: sudo 와 전역 npm 설치는 먼저 물어보세요. 이미 설치돼 있으면 다시 설치하지 마세요. 만든 파일은 바탕화면이 아니라 현재 폴더에 두세요.
출력: 실행한 명령, 설치 경로, 만든 HTML 파일 경로, 남은 오류
검증: `~/.claude/skills/anatomy/SKILL.md` 가 있어야 하고, 만든 HTML 파일을 브라우저로 열었을 때 그림이 보여야 합니다. 둘 중 하나라도 아니면 완료로 보고하지 말고 실패한 명령과 원인을 알려 주세요.

Quick Start

  • 공식 저장소: wheresryan22/anatomy
  • 한 줄 정의: 설명하고 싶은 개념을 그 원리대로 움직이는 물건으로 바꿔, 부품이 많은 아이소메트릭 그림(SVG·WebGL)으로 그려 주는 클로드 스킬입니다.
  • 인기·만든 곳: 2026년 11월 22일 확인 기준 GitHub 스타 28,599개, 최신 판은 v1.1.0입니다. 2026년 10월 8일에 공개된 저장소입니다.
  • 라이선스: MIT. 개인 일과 기관 업무에 자유롭게 쓸 수 있습니다.
  • 필요한 환경: 클로드 코드, Node.js 20.10 이상(설치 도구 skills 는 22.20 이상을 요구), 그림을 스스로 검사할 때 쓰는 크롬
  • 비용: 스킬은 무료입니다. 클로드 사용 요금은 따로 나갑니다. 그림 한 장에 부품이 수십 개라 토큰을 꽤 씁니다.

터미널에서 한 줄, 클로드 코드에서 한 줄이 전부입니다.

터미널에서 입력.

터미널에서 실행
npx skills add wheresryan22/anatomy -g -a claude-code

클로드 코드 안에서 입력.

붙여넣을 글
/anatomy explain how a token bucket rate limiter works, interactive
검증: 2026-11-22 기준 README를 따랐습니다. 이 자료에서는 설치와 그림 생성을 직접 돌려 보지 않았습니다.

STEP 1. Node.js 확인하기: 2분

이 단계에서는 설치 도구가 돌아갈 환경을 확인합니다.

터미널에서 node -v 를 칩니다. v22.20.0 처럼 22.20 이상이 나오면 됩니다. 없거나 낮으면 nodejs.org 에서 LTS 판을 받으세요.

용어: Node.js는 자바스크립트를 컴퓨터에서 돌리는 프로그램입니다. anatomy는 그림을 만들고 검사할 때 Node.js에 기본으로 들어 있는 기능만 써서, 따로 깔 라이브러리가 없습니다.

STEP 2. 스킬 설치하기: 2분

이 단계에서는 클로드 코드가 anatomy를 알아보게 합니다.

Quick Start의 터미널 명령을 실행하면 ~/.claude/skills/anatomy 폴더가 생깁니다. 예시 그림까지 같이 받아서 10MB쯤 됩니다. 클로드 코드가 켜져 있으면 바로 인식합니다. 목록에 안 보이면 /reload-skills 를 치세요.

npx가 안 되는 환경이라면 git으로도 됩니다.

터미널에서 실행
git clone https://github.com/wheresryan22/anatomy.git ~/.claude/skills/anatomy

STEP 3. 첫 그림 만들기: 10분

이 단계에서는 업무 주제로 그림 한 장을 만듭니다.

/anatomy 뒤에 무엇을 설명하고 싶은지 한 문장으로 씁니다. 스킬 이름을 빼고 「작동 원리를 아이소메트릭 그림으로 보여 줘」라고 해도 알아서 불러옵니다.

  • ❌ 이렇게 말고: 「지방세 그림 그려 줘」
  • ✅ 이렇게: 「등록면허세가 본점 소재지에서 걷히고 실제 영업지는 세수를 못 받는 구조를 설명해 줘, 인터랙티브」

클로드는 개념에 맞는 물건을 먼저 정합니다. README의 예로는 「바뀐 게 없으면 작업을 건너뛰는 캐시」가 「핀이 모두 맞을 때만 돌아가는 자물쇠」가 됩니다. 그다음 부품을 하나씩 그리고, 크롬으로 확대해 이음새가 어긋나지 않았는지 스스로 확인합니다.

STEP 4. 결과물 쓰기: 3분

이 단계에서는 만든 그림을 문서에 넣습니다.

결과는 HTML 파일 한 장입니다. 홈페이지나 블로그에는 그대로 올리면 움직이는 그림이 됩니다. 한글 보고서에는 브라우저에서 화면을 캡처해 넣으세요. 밝은 테마와 어두운 테마를 모두 지원합니다.

자주 막히는 곳

  • npx skills 가 Node 버전 오류를 냅니다: 설치 도구가 22.20 이상을 요구합니다. Node를 올리거나 STEP 2의 git 방법을 쓰세요.
  • 그림은 나오는데 검사 단계에서 멈춥니다: 크롬이 없거나 실행이 막힌 경우입니다. 그림 파일 자체는 이미 만들어져 있습니다.
  • 한글 글자가 깨집니다: 그림 안 글자를 영어로 두고, 문서 본문에서 한국어로 설명하는 편이 안전합니다.

솔직히 한계

  • 기술 개념(캐시, 대기열, 엔진)을 설명하려고 만든 도구라, 법·제도처럼 물건으로 바꾸기 어려운 주제는 비유가 억지스러울 수 있습니다. 결과를 보고 맞는지 판단은 직접 해야 합니다.
  • 그림 한 장에 시간이 걸리고 토큰도 많이 씁니다. 상자와 화살표면 충분한 자료라면 그쪽이 빠릅니다.
  • 예시 갤러리는 영어 기준입니다.
