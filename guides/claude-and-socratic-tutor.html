AI 가이드

AI에게 설명 대신 질문을 받으며 공부하는 4단계

읽는 데 12분스텝 4개섹션 7개2026-11-22 공개

이번 주 트렌드 · janestreet/agent_skills

새 업무를 맡거나 시험을 준비할 때, 설명을 읽으면 아는 것 같은데 막상 써 보려면 막힙니다. AI에게 「설명해 줘」라고 하면 긴 글이 오고, 읽고 나면 또 아는 것 같습니다. socratic-tutor는 미국 트레이딩 회사 제인 스트리트(Jane Street)가 사내에서 쓰던 것을 공개한 스킬입니다. 클로드가 설명하는 대신 한 번에 질문 하나씩 던지고, 틀리면 답을 알려 주지 않고 더 좁은 질문으로 다시 묻습니다. 실력은 0~5단계 표로 기록하고, 앞에서 배운 것을 예고 없이 다시 물어봅니다.

복사해서 바로 시작하는 프롬프트. 설치부터 첫 수업까지 AI에게 맡기기.

클로드 코드를 쓰는 분의 첫 메시지로 붙여넣으세요.

복사해서 바로 시작하는 프롬프트
역할: 이 컴퓨터의 클로드 코드에 socratic-tutor 스킬을 설치하는 담당
맥락: 저는 개발 경험이 적습니다. 공부할 주제를 AI에게 질문을 받으면서 익히고 싶습니다.
작업: ① `ls ~/.claude/skills/socratic-tutor/SKILL.md` 로 이미 설치됐는지 보세요. ② 없으면 임시 폴더에 `git clone --depth 1 https://github.com/janestreet/agent_skills.git` 를 받고, 그 안의 `socratic-tutor` 폴더만 `~/.claude/skills/` 로 복사한 뒤 임시 폴더를 지우세요. ③ 설치가 끝나면 첫 수업을 시작하는 문장 예시 두 개를 알려 주세요.
제약: 이미 설치돼 있으면 덮어쓰지 마세요. `~/.claude/skills/` 의 다른 폴더는 건드리지 마세요.
출력: 실행한 명령, 설치 경로, 남은 오류
검증: `~/.claude/skills/socratic-tutor/SKILL.md` 첫 줄 근처에 `name: "socratic-tutor"` 가 보여야 합니다. 보이지 않으면 완료로 보고하지 말고 원인을 알려 주세요.

Quick Start

  • 공식 저장소: janestreet/agent_skills
  • 한 줄 정의: AI를 엄격한 개인 과외 선생으로 바꿔, 진단 질문으로 수준을 재고 한 번에 질문 하나씩 던지며 0~5단계 실력표로 끝까지 가르치게 하는 스킬입니다.
  • 인기·만든 곳: 2026년 11월 22일 확인 기준 GitHub 스타 10,586개입니다. 2026년 11월 3일에 공개됐고, 정식 판 번호는 없습니다. 지금 들어 있는 스킬은 socratic-tutor 하나입니다.
  • 라이선스: MIT. 개인 일과 기관 업무에 자유롭게 쓸 수 있습니다.
  • 필요한 환경: 클로드 코드(또는 SKILL.md를 읽는 다른 에이전트). 일반 클로드 채팅에서는 SKILL.md 내용을 붙여넣어 써도 됩니다.
  • 비용: 무료입니다. 클로드 사용 요금은 따로 나갑니다.

터미널에서 아래 네 줄이면 설치가 끝납니다.

터미널에서 입력.

터미널에서 실행
cd /tmp && git clone --depth 1 https://github.com/janestreet/agent_skills.git
mkdir -p ~/.claude/skills
cp -R /tmp/agent_skills/socratic-tutor ~/.claude/skills/
rm -rf /tmp/agent_skills
검증: 2026-11-22 기준 저장소의 socratic-tutor/SKILL.md 를 직접 읽고 정리했습니다. 설치 명령은 README의 「스킬 폴더에 복사」 안내를 명령으로 옮긴 것입니다.

STEP 1. 설치하기: 2분

이 단계에서는 스킬 폴더 하나를 클로드 코드 스킬 자리에 넣습니다.

Quick Start의 네 줄을 실행합니다. 저장소에는 앞으로 다른 스킬이 늘 수 있어서, 필요한 socratic-tutor 폴더만 복사합니다. 클로드 코드를 다시 켜면 인식합니다.

클로드 코드를 안 쓴다면 SKILL.md 본문을 복사해 클로드 채팅의 프로젝트 지침에 넣어도 같은 방식으로 움직입니다.

STEP 2. 수업 시작하기: 5분

이 단계에서는 주제를 정하고 진단을 받습니다.

「가르쳐 줘」「퀴즈 내 줘」처럼 배우겠다는 뜻이 분명해야 스킬이 켜집니다. 「○○가 뭐야?」라고 물으면 평소처럼 답만 합니다.

  • ❌ 이렇게 말고: 「지방재정법이 뭐야?」
  • ✅ 이렇게: 「지방재정법의 예산 편성 절차를 제대로 익히고 싶어. 가르쳐 줘」

클로드는 주제를 4~10개 작은 기술로 나누고, 쉬운 것부터 어려운 것까지 3~5개 질문으로 지금 수준을 잽니다. 진단이 끝나기 전에는 아무것도 가르치지 않습니다.

STEP 3. 질문에 답하며 익히기: 30분 이상

이 단계가 본 수업입니다.

질문은 한 번에 하나씩 오고, 질문 뒤에 힌트를 달지 않습니다. 틀리면 답 대신 내 생각의 모순이 보이는 더 좁은 질문이 옵니다. 두세 번 틀린 뒤에야 짧게 설명하고, 곧바로 다른 각도에서 다시 묻습니다. 맞혀도 「정말요? 이런 경우는요?」라고 반박해서, 맞는 답을 끝까지 지킬 수 있는지 봅니다.

단계가 바뀔 때마다 이런 실력표가 나옵니다.

붙여넣을 글
Topic: 지방재정법 예산 편성            overall: ######.... 58%
-----------------------------------------------------------------
예산 편성 일정         [########..]  4/5  * independent
세입 추계             [######....]  3/5  <- current focus
추경 요건             [##........]  1/5
-----------------------------------------------------------------

STEP 4. 마무리 평가 받기: 10분

이 단계에서는 정말 익혔는지 확인합니다.

모든 기술이 높은 단계에 오르면 마지막 평가를 합니다. 5단계는 예외 상황이나 꼬아 낸 질문까지 처리해야 받습니다. 단계는 서로 다른 확인 두 번 이상을 통과해야 오르고, 그중 한 번은 설명을 들은 직후가 아닌 시점에 스스로 떠올려야 합니다.

자주 막히는 곳

  • 스킬이 안 켜지고 설명만 길게 나옵니다: 「가르쳐 줘」「퀴즈 내 줘」처럼 배우겠다는 말을 넣으세요.
  • 질문이 영어로 나옵니다: 첫 메시지에 「한국어로 진행해 줘」라고 쓰세요.
  • 한 번에 끝내기엔 깁니다: 중간에 「지금까지 실력표 보여 줘」라고 해서 표를 저장해 두고, 다음에 그 표를 붙여넣고 이어 가세요.

솔직히 한계

  • 엄격하게 만들어서 답답할 수 있습니다. 빨리 개념만 훑고 싶을 때는 맞지 않습니다.
  • 클로드가 아는 범위 안에서만 가르칩니다. 최근 개정된 법령처럼 기억이 틀릴 수 있는 주제는 원문을 함께 주세요.
  • 대화가 끝나면 실력표가 사라집니다. 기록은 직접 남겨야 합니다.
