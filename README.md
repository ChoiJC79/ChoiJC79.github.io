# 나를 정리하는 프로젝트

> 최승환 — ENFP, 지방행정 연구자, 제천시청 팀장  
> 생각날 때 키워드 하나만 던지면 Claude가 정리해줍니다.

---

## 파일 구조

| 파일 | 내용 |
|------|------|
| 💡 아이디어·기획.md | 사업 구상, 정책 아이디어, 창작 메모 |
| 🎯 목표·계획·다짐.md | 장단기 목표, 방향성, 다짐 |
| 📖 일상·감정·회고.md | 하루 기록, 감정, 반성 |
| 📚 업무·논문·공부.md | 지방세 연구, 행정 인사이트, 공부 메모 |

## 사용법

### Claude에게 말하기 (가장 편함)
"아이디어: 제천 청년 창업 공간"  
"목표: 2027 박사 입학"  
"회고: 오늘 보고서 잘 마무리했다"  
"논문: 납세지 불일치 데이터 확보 방안 고민 중"

→ Claude가 자동으로 해당 파일에 날짜와 함께 추가합니다.

### 직접 파일에 쓰기
마크다운 편집기(Typora, Obsidian, VSCode 등)로 열어서 직접 입력
