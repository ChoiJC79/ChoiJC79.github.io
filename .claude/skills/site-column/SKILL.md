# 칼럼 올리기

1. **주제와 재료 받기**: 운영자가 준 메모·초안·경험을 읽는다. 행정·정책인지 삶의 기록인지 정한다.
2. **초안 쓰기**: 프로젝트 CLAUDE.md의 「글쓰기·문서 작성 기준」과 카테고리별 톤을 따른다. 칼럼 말투는 단정하지 않고 여지를 남긴다. 긴 줄표는 쓰지 않는다.
3. **채팅에 초안 전체를 보여 승인받는다.** 승인 전에는 파일을 건드리지 않는다. 고칠 점이 있으면 반영해 다시 보인다.
4. **발행 정보 확인**: 제목, 날짜(YYYY-MM-DD, 기본은 오늘), 태그(가운뎃점 구분, 예 `지방세·행정연구`), type(`policy`=행정·정책 A면, `life`=삶의 기록 B면), 대표 사진(Mac 파일 경로 또는 저장소의 `/img/파일명`). 사진이 없으면 `ls img/col_*`에서 어울리는 것을 골라 제안한다.
5. **배포**: 스크래치패드에 JSON을 쓰고 실행한다.
   ```json
   {"title": "...", "date": "2026-11-22", "tags": "에세이·일상", "body": "마크다운 본문(제목 줄 제외)", "type": "life", "image": "/img/col_family.jpg"}
   ```
   ```bash
   python3 site_mcp.py --add column /경로/초안.json
   ```
   md 추가, column.html 목록·카드, columns/{슬러그}.html, sitemap, 커밋·push를 한 번에 한다.
6. **결과 보고**: 출력된 주소를 알려 준다. 커밋 검사(윤문게이트)에 걸리면 걸린 표현을 고쳐 다시 실행한다. 이때 md에 이미 들어간 블록이 있으면 `git restore`로 되돌린 뒤 실행한다.
