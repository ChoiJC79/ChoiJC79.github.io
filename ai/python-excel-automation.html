파이썬 업무 스크립트 — 반복되는 엑셀 취합을 자동화하기

읍면동별·부서별로 받은 엑셀 파일을 하나로 합치는 작업은 매달 반복되지만 실수가 잦습니다. 파이썬 스크립트 하나로 폴더 안 파일을 자동 취합하면, 사람은 결과 검증에만 시간을 쓰면 됩니다. AI에게 요구사항을 설명하면 스크립트 초안을 받을 수 있습니다.

2026-09-05 · 최승환

When이럴 때 쓰세요

  • 같은 양식의 엑셀 파일 수십 개를 매달 합쳐야 할 때
  • 취합 과정에서 복사·붙여넣기 실수가 반복될 때
  • 합친 결과로 요약표까지 자동으로 만들고 싶을 때

How따라하기

양식을 설명한다

시트 이름, 머리글 행 위치, 열 구성을 정확히 알려 줍니다.

입력과 출력을 정한다

'input 폴더의 모든 xlsx를 읽어 output/취합.xlsx로 저장'처럼 경로를 지정합니다.

예외 처리를 요청한다

양식이 다른 파일이 섞였을 때 멈추지 말고 목록으로 알려 주도록 요청합니다.

작은 표본으로 시험한다

파일 2~3개로 먼저 돌려 결과를 손 계산과 대조합니다.

실행 방법을 문서로 남긴다

설치할 라이브러리와 실행 명령을 메모해 두면 후임자도 쓸 수 있습니다.

Prompt바로 쓰는 프롬프트

파이썬 스크립트를 작성해줘.
- input 폴더의 모든 .xlsx 파일을 읽는다
- 각 파일의 첫 시트, 1행이 머리글, 열: 읍면동 / 세목 / 부과액
- 전부 합쳐 output/취합.xlsx로 저장하고, 두 번째 시트에 읍면동×세목 합계 피벗표를 만든다
- 열 구성이 다른 파일은 건너뛰고 파일명을 출력한다
- pandas와 openpyxl 사용, 실행 방법도 함께 알려줘

Caution주의할 점

  • 실제 과세자료로 작업할 때는 기관 PC 안에서만 실행하고 외부로 전송하지 않습니다.
  • 스크립트 결과는 첫 몇 달간 수작업 결과와 병행 비교해 신뢰성을 확인합니다.
매달 하는 일이라면, 한 번 만들어 두는 편이 이깁니다.
