📐 CLAUDE.md와 스킬 — AI에게 나의 작업 규칙 가르치기

매번 같은 설명을 반복하는 대신, 프로젝트의 규칙과 선호를 문서로 적어 두면 AI가 작업을 시작할 때마다 읽고 따릅니다. Claude Code에서는 CLAUDE.md 파일과 스킬(Skill)이 그 역할을 합니다.

2026-09-09 · 약 2분

이럴 때

  • 매번 '보고서체로', '에스파냐로 표기' 같은 규칙을 반복 설명하고 있을 때
  • 프로젝트의 배포 절차·파일 구조를 AI가 자주 헷갈릴 때
  • 특정 작업(칼럼 발행, 보고서 서식)을 표준 절차로 고정하고 싶을 때

핵심

한 번 적어 두면, 매번 설명하지 않아도 됩니다.

꼭 지킬 것

규칙 문서가 너무 길면 오히려 중요한 규칙이 묻힙니다. 핵심 위주로 유지합니다.

따라 하기

  1. 반복 설명을 모은다지난 대화에서 여러 번 반복한 지시사항을 목록으로 적어 봅니다.
  2. CLAUDE.md에 규칙을 적는다프로젝트 루트의 CLAUDE.md에 파일 구조, 문체 기준, 금지 사항을 간결하게 기록합니다.
  3. 절차는 단계로 적는다'1. 원고 확인 요청 → 2. md 파일 추가 → 3. 빌드 → 4. 배포'처럼 순서를 번호로 명시합니다.
  4. 특정 작업은 스킬로 분리한다자주 쓰는 전문 작업은 별도 스킬로 만들어 필요할 때만 불러오게 합니다.
  5. 실제로 어긋날 때마다 보완한다AI가 규칙을 어긴 사례가 생기면 그 내용을 문서에 추가해 점점 정교하게 다듬습니다.

바로 쓰는 프롬프트

지금까지 우리 대화에서 내가 반복해서 요구한 규칙과 선호를 정리해
CLAUDE.md에 넣을 수 있는 형태로 작성해줘.
- 섹션: 프로젝트 개요 / 파일 구조 / 글쓰기 기준 / 작업 절차 / 주의사항
- 각 규칙은 한 줄로, 이유가 필요한 규칙만 짧게 이유 추가

함께 챙길 것

  • 비밀번호·토큰 같은 민감 정보는 규칙 문서에 적지 않습니다.
