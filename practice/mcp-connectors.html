AI 실무 가이드 · 자동화

🔌 MCP 커넥터 — AI를 노션·드라이브·캘린더와 연결하기

MCP(Model Context Protocol)는 AI가 외부 서비스의 데이터와 기능을 표준 방식으로 사용할 수 있게 해 주는 연결 규격입니다. 커넥터를 연결하면 AI가 문서를 직접 찾아 읽고, 일정을 확인하고, 노트에 결과를 저장하는 흐름을 한 번의 대화 안에서 처리할 수 있습니다.

2026-09-13 · 약 2분

이럴 때

  • 여러 서비스를 오가며 복사·붙여넣기를 반복하고 있을 때
  • AI가 만든 결과를 노션·드라이브에 바로 저장하고 싶을 때
  • 내 일정과 메일을 바탕으로 하루 업무 정리를 받고 싶을 때

핵심

복사·붙여넣기가 사라지는 지점에서 자동화가 시작됩니다.

꼭 지킬 것

업무 계정과 개인 계정을 분리해 연결하고, 기관 보안 정책상 허용된 서비스만 연결합니다.

따라 하기

  1. 연결할 서비스를 고른다가장 자주 복사·붙여넣기를 하는 서비스 하나부터 연결합니다.
  2. 권한 범위를 확인한다커넥터가 읽기만 하는지, 쓰기·삭제까지 하는지 연결 전에 확인합니다.
  3. 작은 작업으로 시험한다'최근 노션 페이지 5개 제목만 보여줘'처럼 읽기 작업부터 시작합니다.
  4. 쓰기 작업은 확인을 거친다메일 발송·파일 삭제처럼 되돌리기 어려운 작업은 실행 전 확인하도록 설정합니다.
  5. 업무 흐름으로 묶는다'자료 검색 → 요약 → 노션 저장'처럼 자주 하는 흐름을 하나의 요청 문장으로 정리해 둡니다.

바로 쓰는 프롬프트

내 구글 드라이브에서 '등록면허세'가 포함된 최근 문서 3개를 찾아
각 문서의 핵심 내용을 3줄씩 요약하고,
그 결과를 노션에 '주간 자료 정리' 페이지로 만들어줘.
페이지를 만들기 전에 요약 내용을 먼저 보여주고 확인을 받아줘.

함께 챙길 것

  • 외부 문서·메일 본문에 AI를 속이려는 지시문이 들어 있을 수 있으므로 실행 결과를 확인하는 습관이 필요합니다.
  • 필요 없어진 커넥터는 연결을 해제합니다.
