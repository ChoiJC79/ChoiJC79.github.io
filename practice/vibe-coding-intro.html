AI 실무 가이드 · 코딩

🎧 바이브코딩이란 — 말로 만드는 프로그램

바이브코딩은 코드를 한 줄씩 직접 쓰는 대신, 원하는 결과를 자연어로 설명하고 AI가 만든 코드를 실행·수정하며 프로그램을 완성해 가는 방식입니다. 개발자가 아니어도 업무용 작은 도구를 직접 만들 수 있는 길이 열렸습니다.

2026-08-24 · 약 2분

이럴 때

  • 반복 업무를 줄여 줄 작은 도구가 필요하지만 개발 의뢰까지는 과할 때
  • 개인 홈페이지·대시보드를 직접 만들어 보고 싶을 때
  • 아이디어를 빠르게 시제품으로 만들어 검증하고 싶을 때

핵심

코드를 몰라도 되지만, 무엇을 만들지는 분명히 알아야 합니다.

꼭 지킬 것

작동한다고 해서 안전한 것은 아닙니다. 개인정보를 다루는 도구는 반드시 전문가 검토를 거칩니다.

따라 하기

  1. 완성된 모습을 말로 그린다'엑셀 파일을 올리면 읍면동별 합계 그래프가 나오는 웹페이지'처럼 입력과 결과를 설명합니다.
  2. 작게 시작한다처음부터 모든 기능을 요청하지 말고 핵심 기능 하나가 작동하는 버전부터 만듭니다.
  3. 실행하고 결과를 알려 준다오류가 나면 오류 메시지를 그대로 복사해 전달합니다. 추측보다 실제 메시지가 빠른 해결로 이어집니다.
  4. 기능을 하나씩 붙인다작동하는 버전을 저장해 두고, 기능을 하나 추가할 때마다 다시 확인합니다.
  5. 버전 관리를 익힌다Git으로 단계별 저장을 해 두면 잘못된 수정을 언제든 되돌릴 수 있습니다.

바로 쓰는 프롬프트

HTML 파일 하나로 동작하는 웹페이지를 만들어줘.
- 기능: CSV 파일을 선택하면 첫 열(지역)별로 둘째 열(금액) 합계를 막대그래프로 표시
- 외부 서버 없이 브라우저에서만 동작
- 처음 버전은 그래프 표시까지만. 디자인은 단순하게.

함께 챙길 것

  • AI가 만든 코드라도 무엇을 하는지 한 번은 설명을 들어 두는 것이 유지보수에 도움이 됩니다.
