🌐 정적 홈페이지 만들기 — GitHub Pages와 AI로 나만의 사이트 운영

GitHub Pages는 저장소에 올린 HTML 파일을 그대로 웹사이트로 공개해 주는 무료 호스팅 서비스입니다. 서버 관리 없이 글·연구 포트폴리오를 운영할 수 있고, AI와 함께라면 디자인과 페이지 추가도 어렵지 않습니다. 이 사이트도 같은 방식으로 운영하고 있습니다.

2026-09-01 · 약 2분

이럴 때

  • 연구 성과·칼럼을 한곳에 모아 공개하고 싶을 때
  • 블로그 플랫폼의 디자인 제약에서 벗어나고 싶을 때
  • 서버 비용 없이 개인 사이트를 오래 유지하고 싶을 때

핵심

HTML 파일 하나가 곧 하나의 페이지입니다. 시작은 생각보다 가볍습니다.

꼭 지킬 것

공개 저장소에 올린 파일은 누구나 볼 수 있습니다. 개인 연락처·내부 자료를 올리지 않습니다.

따라 하기

  1. 저장소를 만든다'사용자명.github.io' 이름으로 저장소를 만들면 해당 주소로 사이트가 열립니다.
  2. 첫 페이지를 AI와 만든다사이트 성격과 원하는 메뉴를 설명하고 index.html 한 파일부터 만듭니다.
  3. 공통 디자인을 분리한다페이지가 늘어나면 색상·글꼴을 공통 CSS 파일로 분리해 일관성을 유지합니다.
  4. 반복 페이지는 템플릿으로 만든다칼럼·가이드처럼 구조가 같은 페이지는 템플릿과 데이터로 나눠 생성하면 관리가 쉬워집니다.
  5. 검색 노출을 챙긴다페이지마다 제목·설명·OG 메타태그를 넣고 sitemap.xml을 갱신합니다.

바로 쓰는 프롬프트

GitHub Pages에 올릴 개인 연구 사이트의 index.html을 만들어줘.
- 메뉴: 소개 / 연구 / 칼럼 / 가이드
- 다크 톤, 본문 글꼴은 Noto Sans KR
- 모바일에서도 깨지지 않게
- 각 메뉴는 아직 빈 페이지로 연결만
