🤖 Claude Code 입문 — 저장소와 대화하며 개발하기

Claude Code는 터미널·데스크톱·웹 등에서 코드 저장소를 직접 읽고 파일을 수정하며 명령을 실행하는 Anthropic의 AI 코딩 도구입니다. 채팅창에 코드를 복사해 붙이는 방식과 달리, 프로젝트 전체 맥락을 보고 작업한다는 점이 가장 큰 차이입니다.

2026-08-28 · 약 2분

이럴 때

  • 여러 파일에 걸친 수정을 한 번에 해야 할 때
  • 기존 프로젝트 구조를 파악하고 설명을 듣고 싶을 때
  • 반복되는 페이지 생성·배포 작업을 자동화하고 싶을 때

핵심

코드를 붙여 넣는 AI에서, 프로젝트를 함께 보는 AI로.

꼭 지킬 것

파일 삭제·강제 푸시 같은 되돌리기 어려운 작업은 실행 전에 반드시 확인합니다.

따라 하기

  1. 작업할 저장소에서 시작한다프로젝트 폴더를 열고 Claude Code를 실행하면 해당 저장소를 기준으로 작업합니다.
  2. 먼저 구조를 묻는다'이 프로젝트의 파일 구조와 역할을 설명해줘'로 시작하면 AI와 내가 같은 그림을 보게 됩니다.
  3. 작업을 구체적으로 요청한다'column.html에 새 칼럼 카드를 추가하고 목록 날짜순을 유지해줘'처럼 대상 파일과 조건을 밝힙니다.
  4. 변경 내용을 검토한다수정된 파일의 차이(diff)를 확인하고, 의도와 다르면 바로 되돌리거나 재요청합니다.
  5. 커밋 단위로 마무리한다의미 있는 작업 하나가 끝날 때마다 커밋해 두면 이력 관리가 쉬워집니다.

바로 쓰는 프롬프트

이 저장소의 파일 구조와 각 파일의 역할을 표로 정리해줘.
그다음, 새 페이지를 추가할 때 수정해야 하는 파일 목록과 순서를 알려줘.
아직 파일은 수정하지 마.

함께 챙길 것

  • 비밀번호·토큰이 담긴 파일이 커밋되지 않도록 .gitignore를 점검합니다.
  • 도구의 기능과 요금 정책은 바뀔 수 있으니 공식 문서를 확인합니다.
