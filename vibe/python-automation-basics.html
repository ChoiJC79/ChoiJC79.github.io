13. 파이썬 기초와 pathlib 파일 자동화

가상환경을 구축하고 `pathlib`과 올바른 인코딩으로 폴더 내 행정 파일을 일괄 처리하는 파이썬 스크립트를 실행할 수 있다.

개념 읽기 → 실습 → 요점 카드 모두 「안다」 → 튜터와 대화로 다지기

왜 여기서 막히나

AI에게 파이썬 코드를 요청해도 실행 환경과 인코딩 개념을 모르면 오류 창에서 작업을 멈추게 됩니다. 다른 프로그램과의 충돌을 방지하는 `venv` 가상환경과 한글 깨짐을 막는 `cp949`, `utf-8` 구분을 알아야 정상 동작합니다. 폴더 안 수십 개 엑셀 파일을 하나씩 열지 않고 한 번에 순회하려면 `pathlib` 기본 구조를 파악해야 합니다. 이 기초를 알면 AI가 작성한 코드의 파일 경로와 실행 방식을 직접 검토하고 오류를 바로잡을 수 있습니다.

핵심 개념 세 가지

  1. 가상환경 venv프로젝트마다 독립된 파이썬 실행 공간을 만드는 표준 기능입니다. 맥 기본 환경을 건드리지 않고 필요한 패키지만 설치하여 라이브러리 충돌을 예방합니다. 터미널에서 python3 -m venv .venv 명령으로 생성하고 source .venv/bin/activate 명령으로 활성화합니다.
  2. pathlib 경로 처리운영체제에 구애받지 않고 파일과 디렉터리 경로를 다루는 파이썬 기본 모듈입니다. Path('폴더경로').glob('*.csv') 구문을 사용하면 특정 확장자를 가진 파일을 일괄 탐색합니다. 문자열 연산 대신 슬래시 기호를 활용하여 하위 경로를 안전하게 생성합니다.
  3. 한글 파일 인코딩텍스트를 컴퓨터가 읽는 방식으로 온나라 시스템이나 행정 엑셀에서 내려받은 파일은 주로 cp949 방식을 씁니다. 웹과 맥 환경의 기본 표준은 utf-8 방식입니다. 파이썬에서 open() 함수로 파일을 다룰 때 encoding='cp949' 또는 encoding='utf-8' 매개변수를 명시하지 않으면 글자가 깨집니다.

자주 쓰는 코드

import sys  # 명령줄 인자 처리를 위한 모듈을 가져옵니다
from pathlib import Path  # 경로 처리를 위한 객체를 가져옵니다

folder_path = Path(sys.argv[1])  # 첫 번째 실행 인자로 전달받은 폴더 경로를 지정합니다
output_file = folder_path / '목록.txt'  # 결과 목록을 저장할 파일 경로를 생성합니다

with open(output_file, 'w', encoding='utf-8') as out:  # 결과 파일을 utf-8 형식으로 엽니다
    for file in folder_path.glob('*.csv'):  # 폴더 내부의 모든 csv 파일을 순회합니다
        with open(file, 'r', encoding='cp949') as src:  # 행정 csv 파일을 cp949 형식으로 읽습니다
            header = src.readline().strip()  # 첫 번째 줄의 제목 행을 읽고 줄바꿈을 제거합니다
            out.write(f'{file.name}: {header}\n')  # 파일명과 제목 행을 결과 파일에 기록합니다

같은 일, 다른 요청

이렇게 요청하면

폴더에 있는 문서들 제목 행 읽어서 목록 파일로 저장해 줘.

이렇게 요청한다

`python3` 기본 라이브러리인 `pathlib`과 `sys.argv`를 사용하는 스크립트를 작성해 주십시오.
`sys.argv[1]`로 전달받은 폴더 경로 안의 모든 `*.csv` 파일을 순회해야 합니다.
입력 파일은 지자체 시스템에서 내려받은 `cp949` 인코딩 파일이며, 첫 번째 제목 행만 추출합니다.
추출 결과는 해당 폴더 안에 `목록.txt`라는 이름으로 `utf-8` 인코딩으로 저장해 주십시오.
터미널에서 가상환경 생성부터 실행하는 전체 명령어 순서도 포함해 주십시오.

입력 파일 인코딩 형식과 경로 탐색 도구를 직접 지정하여 한글 깨짐 현상과 경로 오류를 방지합니다. 실행 인자를 명시하여 특정 폴더 경로가 고정되지 않고 재사용 가능한 스크립트를 확보합니다. 터미널 실행 단계까지 함께 요청하므로 환경 설정부터 결과 확인까지 막힘없이 진행할 수 있습니다.

30분 실습

  1. 터미널에서 실습 폴더를 만들고 python3 -m venv .venv 명령으로 가상환경을 생성한 뒤 source .venv/bin/activate 명령으로 활성화합니다.
  2. pip install pandas 명령을 입력하여 데이터 처리 라이브러리를 가상환경 내부에 설치합니다.
  3. pathlib과 sys.argv를 사용해 폴더 내 *.csv 파일의 첫 줄을 읽는 collect.py 스크립트를 작성합니다.
  4. python3 collect.py ./실습자료 명령으로 스크립트를 실행하고 생성된 목록.txt 파일을 열어 한글 정상 출력 여부를 확인합니다.

통과 기준

  • 터미널 프롬프트 앞에 (.venv) 표시가 나타나 가상환경 활성화를 확인합니다.
  • 실습 폴더 내부에 목록.txt 파일이 정상적으로 생성되어 있습니다.
  • 목록.txt 파일을 열었을 때 파일명과 행정 데이터 제목 행 한글이 깨짐 없이 온전히 출력됩니다.

요점 카드

질문을 보고 답을 먼저 떠올린 뒤 눌러서 확인합니다. 답을 보지 않고 말할 수 있는 카드에만 「안다」를 표시하고, 모든 카드에 표시하면 이 단계를 통과합니다.

  1. macOS 터미널에서 .venv 이름의 파이썬 가상환경을 생성하는 명령어는?

    python3 -m venv .venv 명령을 실행합니다.

  2. 생성한 파이썬 가상환경을 터미널에서 활성화하는 명령어는?

    source .venv/bin/activate 명령을 실행합니다.

  3. 패키지 목록이 적힌 requirements.txt 파일을 보고 일괄 설치하는 명령어는?

    pip install -r requirements.txt 명령을 실행합니다.

  4. pathlib을 이용해 특정 폴더의 모든 엑셀 파일(.xlsx)을 찾는 구문은?

    Path('폴더경로').glob('*.xlsx') 구문을 사용합니다.

  5. 스크립트 실행 시 터미널에서 넘겨준 첫 번째 인자 값을 가져오는 코드는?

    import sys 선언 후 sys.argv[1] 값을 조회합니다.

  6. 지자체 공공데이터 CSV 파일의 한글이 깨질 때 open() 함수에 지정할 인코딩 값은?

    encoding='cp949' 또는 encoding='euc-kr' 값을 지정합니다.

튜터와 다지기

문제를 맞혔어도 내 프로젝트에서 바로 쓰지 못하면 아직 아는 것이 아닙니다. 아래 프롬프트를 Claude에 붙여 넣으면 「통과」라고 할 때까지 내 상황에 맞춘 질문을 계속 받습니다.

너는 내 바이브 코딩 튜터다. 나는 「파이썬 기초와 pathlib 파일 자동화」 단계를 공부하고 있다.
이 단계의 목표는 「가상환경을 구축하고 `pathlib`과 올바른 인코딩으로 폴더 내 행정 파일을 일괄 처리하는 파이썬 스크립트를 실행할 수 있다.」
다룰 개념은 「가상환경 venv」, 「pathlib 경로 처리」, 「한글 파일 인코딩」이다.
