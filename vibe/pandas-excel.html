17. pandas와 openpyxl로 엑셀 집계하기

pandas와 openpyxl을 사용해 여러 시트의 엑셀 자료를 필터링하고 집계표로 저장할 수 있다.

개념 읽기 → 실습 → 요점 카드 모두 「안다」 → 튜터와 대화로 다지기

왜 여기서 막히나

행정 업무에서는 매월 각 부서나 읍면동에서 취합한 엑셀 파일 수십 개를 합치고 요약하는 작업이 반복됩니다. 파이썬 기본 기능만으로는 여러 시트를 읽거나 복잡한 조건 집계를 수행하기 어렵습니다. `pandas` 라이브러리를 사용하면 수만 줄의 행정 자료도 몇 줄의 명령으로 필터링하고 그룹별 합계를 계산할 수 있습니다. 기존 엑셀 서식과 테두리를 보존하면서 값만 채워 넣으려면 `openpyxl` 라이브러리의 역할도 함께 알아야 합니다.

핵심 개념 세 가지

  1. read_excel과 sheet_name 매개변수pandas.read_excel() 함수는 엑셀 파일을 읽어 표 형태 객체인 DataFrame으로 변환합니다. sheet_name 매개변수에 시트 이름을 지정하거나 None을 전달하여 모든 시트를 딕셔너리 형태로 한 번에 읽을 수 있습니다. 특정 머리글 행을 지정할 때는 header=0처럼 정수 위치를 전달합니다.
  2. groupby와 pivot_table 집계groupby() 함수는 부서명이나 예산과목 같은 특정 열을 기준으로 데이터를 묶어 합계나 평균을 계산합니다. pivot_table() 함수는 행과 열의 기준을 교차 배치하여 엑셀의 피벗테이블과 동일한 요약표를 만듭니다. 반복적인 엑셀 수식 작성 없이도 데이터 분석 결과를 표 형태로 재구성합니다.
  3. to_excel 저장과 openpyxl 서식 제어pandas의 to_excel() 함수는 연산 결과를 새 엑셀 파일로 저장하지만 기존 셀 서식과 글꼴을 모두 초기화합니다. 기존 양식 파일의 결재란이나 테두리 서식을 유지해야 한다면 openpyxl 라이브러리를 사용해 특정 셀의 값만 수정해야 합니다. 데이터 분석은 pandas로 처리하고 최종 보고서 양식 저장은 openpyxl로 분담하는 방식이 실무 표준입니다.

자주 쓰는 코드

import pandas as pd  # 데이터 분석 라이브러리 pandas를 불러옵니다
df = pd.read_excel('budget.xlsx', sheet_name='2024년')  # 특정 시트 데이터를 읽어옵니다
df['집행액'] = pd.to_numeric(df['집행액'], errors='coerce').fillna(0)  # 숫자가 아닌 값을 0으로 바꿉니다
summary = df.groupby('부서명')['집행액'].sum().reset_index()  # 부서별 집행액 합계를 계산합니다
summary.to_excel('summary.xlsx', index=False)  # 행 번호 인덱스를 제외하고 엑셀 파일로 저장합니다

같은 일, 다른 요청

이렇게 요청하면

엑셀 파일 정리해서 부서별 합계 낸 다음 엑셀로 다시 만들어 줘.

이렇게 요청한다

`budget.xlsx` 파일의 `2024년` 시트를 `pandas.read_excel`로 읽는 파이썬 스크립트를 작성해 주십시오.
`부서명` 열을 기준으로 `집행액` 열의 합계를 구하도록 `groupby('부서명')['집행액'].sum()`을 적용해 주십시오.
결과는 행 번호를 제외하고 `index=False` 옵션을 지정하여 `dept_summary.xlsx` 파일로 저장해 주십시오.
금액 열에 빈칸이나 텍스트가 섞여 있어도 오류가 나지 않도록 `pd.to_numeric` 처리를 포함하고 저장 후 상위 5개 부서의 합계액을 터미널에 출력해 주십시오.

`good` 요청은 읽어올 시트 이름과 집계 기준 열, 결측치 처리 함수를 명확하게 지정합니다. 또한 결과 파일 저장 시 `index=False`를 지정하여 불필요한 번호 열이 생기지 않도록 방지합니다. 최종 결과의 터미널 미리보기까지 요청하므로 실행 후 엑셀 파일을 일일이 열지 않고도 작업 성공을 검증할 수 있습니다.

30분 실습

  1. 실습용 엑셀 파일 expenditure.xlsx를 만들고 부서명, 사업명, 집행액 열에 예시 행정 데이터 10줄을 입력합니다.
  2. 터미널에서 pip install pandas openpyxl 명령을 실행하여 엑셀 처리에 필요한 필수 라이브러리를 설치합니다.
  3. 파이썬 스크립트를 작성하여 read_excel로 데이터를 불러온 뒤 groupby('부서명')['집행액'].sum() 집계를 수행합니다.
  4. to_excel('dept_report.xlsx', index=False) 명령으로 저장하고 생성된 파일의 부서별 집행액 합계가 맞는지 확인합니다.

통과 기준

  • 터미널에서 스크립트를 실행했을 때 에러 메시지 없이 종료 코드 0으로 정상 완료됩니다.
  • 생성된 dept_report.xlsx 파일의 첫 번째 열에 불필요한 0부터 시작하는 숫자 인덱스 열이 존재하지 않습니다.
  • 부서별 집행액 합계 셀의 값이 문자열이 아닌 실제 숫자 형식으로 저장되어 엑셀 자동 합계 기능이 정상 동작합니다.

요점 카드

질문을 보고 답을 먼저 떠올린 뒤 눌러서 확인합니다. 답을 보지 않고 말할 수 있는 카드에만 「안다」를 표시하고, 모든 카드에 표시하면 이 단계를 통과합니다.

  1. 엑셀 파일의 모든 시트를 한 번에 딕셔너리로 읽어오기 위한 read_excel의 매개변수 설정은?

    sheet_name=None입니다. 시트 이름을 딕셔너리의 키로 하고 각 시트의 데이터프레임을 값으로 반환합니다.

  2. to_excel 함수로 데이터프레임을 저장할 때 맨 왼쪽 번호 열을 생성하지 않는 옵션은?

    index=False입니다. 이 옵션을 생략하면 0부터 시작하는 판다스 기본 인덱스가 엑셀의 첫 번째 열로 기록됩니다.

  3. 텍스트가 섞인 숫자 열을 숫자로 변환하고 오류 값을 결측치로 바꾸는 판다스 함수는?

    pd.to_numeric(열, errors='coerce')입니다. 변환할 수 없는 문자는 NaN으로 치환하여 계산 중단을 방지합니다.

  4. 판다스의 to_excel이 지원하지 못하는 기존 엑셀 양식의 서식과 테두리를 보존할 때 사용하는 전용 라이브러리는?

    openpyxl 라이브러리입니다. load_workbook 함수로 기존 파일을 열어 셀 서식을 유지한 상태로 특정 위치의 값만 수정합니다.

  5. 날짜 형식 데이터 열에서 월 단위 기간 정보를 추출하여 새로운 그룹화 기준으로 만드는 판다스 코드는?

    df['날짜열'].dt.to_period('M')입니다. 판다스 datetime 형식의 .dt 접근자를 통해 연월 단위 주기를 생성합니다.

  6. 터미널에서 파이썬 환경에 엑셀 읽기 및 쓰기 라이브러리를 설치하는 명령어는?

    pip install pandas openpyxl입니다. 판다스는 엑셀 파일 입출력 내부 엔진으로 openpyxl을 사용합니다.
