19. requests로 공공데이터 API 호출하기

requests 라이브러리로 공공데이터 API를 호출하여 행정 데이터를 수집하고 JSON 파일로 저장할 수 있다.

개념 읽기 → 실습 → 요점 카드 모두 「안다」 → 튜터와 대화로 다지기

왜 여기서 막히나

행정 포털의 화면을 일일이 복사하거나 수동으로 내려받는 방식은 데이터가 갱신될 때마다 반복 작업을 부릅니다. `requests` 라이브러리를 모르면 웹 자동화를 시도할 때 불필요하게 무거운 브라우저 제어 도구를 사용하다가 잦은 오류를 겪게 됩니다. API 명세서의 요청 주소와 파라미터를 읽을 줄 알면 단 몇 줄의 파이썬 코드로 수천 건의 공공데이터를 바로 확보합니다. 서비스 인증키를 코드 안에 그대로 노출하여 보안 감사에서 지적받는 문제도 사전에 차단합니다.

핵심 개념 세 가지

  1. HTTP GET 요청과 파라미터API 서버에 데이터를 조회할 때 사용하는 표준 방식입니다. 요청 주소 뒤에 물음표를 추가하고 조회 기간이나 정렬 기준 같은 조건을 키와 값 형태로 전달합니다. requests.get() 함수에 params 딕셔너리를 넘기면 안전하게 요청 주소를 완성합니다.
  2. 상태 코드와 응답 JSON서버가 처리 결과를 3자리 숫자로 알려주는 규약입니다. 정상 처리는 200, 인증키 오류는 401, 일일 호출 횟수 제한 초과는 429, 서버 내부 장애는 500을 반환합니다. 응답 객체의 .json() 메서드를 호출하면 수신한 문자열 데이터를 파이썬 딕셔너리로 즉시 변환합니다.
  3. 환경 변수와 타임아웃 설정공공데이터포털에서 발급받은 서비스키는 유출을 막기 위해 코드에 적지 않고 운영체제 환경 변수나 .env 파일에 보관합니다. 공공 서버의 응답 지연으로 스크립트가 멈추는 현상을 방지하기 위해 timeout 옵션을 반드시 지정합니다. 연결 실패에 대비하여 재시도 로직을 구성하면 수집 작업의 안정성을 보장합니다.

자주 쓰는 코드

import os, requests  # 운영체제 환경 변수와 웹 요청 라이브러리를 불러옵니다.
api_key = os.environ.get("DATA_GO_KR_API_KEY")  # 시스템 환경 변수에서 공공데이터 서비스키를 읽어옵니다.
url = "https://apis.data.go.kr/기관번호/서비스명/오퍼레이션"  # 활용 신청한 API의 요청 주소로 바꿉니다.
params = {"serviceKey": api_key, "returnType": "JSON", "numOfRows": 10}  # 서비스키와 조회 건수를 파라미터로 설정합니다.
response = requests.get(url, params=params, timeout=10)  # 10초 타임아웃을 적용하여 서버로 GET 요청을 보냅니다.
if response.status_code == 200:  # 응답 상태 코드가 정상인 200인지 검사합니다.
    data = response.json()  # 응답 본문에서 JSON 데이터를 파이썬 딕셔너리로 변환합니다.
    items = data["response"]["body"]["items"]  # 본문 데이터에서 실제 목록 항목을 추출합니다.
    print(f"조회 성공: {len(items)}건")  # 수신한 데이터 건수를 화면에 출력합니다.

같은 일, 다른 요청

이렇게 요청하면

공공데이터포털에서 우리 지역 민원 통계 가져오는 파이썬 코드 짜줘.

이렇게 요청한다

`requests` 라이브러리를 사용해 공공데이터포털 API를 호출하는 파이썬 스크립트를 작성해 주십시오.
인증키는 코드에 직접 적지 말고 `os.environ.get("PUBLIC_DATA_API_KEY")`로 가져오도록 처리해 주십시오.
요청 파라미터는 `page=1`, `perPage=50`, `returnType=JSON`으로 구성하고 네트워크 지연에 대비해 `timeout=10`을 설정해 주십시오.
응답 상태 코드가 `200`인지 확인하고 `401`, `429`, `500` 오류가 발생하면 원인을 한국어로 출력한 뒤 중단해야 합니다.
정상 응답인 경우 JSON 본문에서 목록 데이터를 추출하여 `data/complaints.json` 파일로 저장하고 총 수집 건수를 콘솔에 출력해 주십시오.

사용할 도구로 `requests`를 명시하고 환경 변수와 파라미터 규칙을 사전에 전달하여 보안 사고와 잘못된 요청을 방지합니다. 상태 코드별 예외 처리와 `timeout` 조건을 지정하여 네트워크 장애 발생 시 스크립트가 무한정 멈추는 문제를 예방합니다. 결과물이 저장될 파일 경로와 검증 방식을 정확히 지시하므로 생성된 코드의 정상 작동 여부를 즉시 판단할 수 있습니다.

30분 실습

  1. 터미널에서 export PUBLIC_DATA_API_KEY="발급받은인증키" 명령으로 공공데이터 서비스키를 환경 변수에 등록합니다.
  2. 작업 폴더에 api_fetch.py 파일을 생성하고 requests 라이브러리를 임포트하는 기본 코드를 작성합니다.
  3. API 명세서에 안내된 기본 주소와 요청 파라미터를 딕셔너리로 작성한 뒤 timeout=10을 설정하여 requests.get()을 실행합니다.
  4. 수신된 응답의 status_code가 200인지 확인하고 수신 데이터를 data/result.json 파일에 저장한 뒤 파일 내용을 검토합니다.

통과 기준

  • 터미널에서 python api_fetch.py 실행 시 콘솔에 상태 코드 200과 함께 수집 건수 숫자가 출력됩니다.
  • 프로젝트 폴더 하위에 data/result.json 파일이 생성되고 내부에 유효한 JSON 형식 데이터가 저장되어 있습니다.
  • 스크립트 코드 원본에 실제 API 비밀키 문자열이 평문으로 노출되어 있지 않습니다.

요점 카드

질문을 보고 답을 먼저 떠올린 뒤 눌러서 확인합니다. 답을 보지 않고 말할 수 있는 카드에만 「안다」를 표시하고, 모든 카드에 표시하면 이 단계를 통과합니다.

  1. requests로 10초 대기 제한을 두고 GET 요청을 보내는 코드는?

    response = requests.get(url, params=params, timeout=10) 한 줄을 실행합니다.

  2. API 응답이 정상인지 확인할 때 검사하는 HTTP 상태 코드는?

    response.status_code == 200 조건을 확인합니다. 200은 서버가 요청을 정상적으로 처리했음을 나타내는 표준 성공 코드입니다.

  3. 공공데이터포털 API에서 인증키가 잘못됐을 때 확인할 곳은?

    HTTP 401로 오기도 하지만, 상태코드는 200인데 본문에 SERVICE_KEY_IS_NOT_REGISTERED_ERROR 같은 오류 문구가 담겨 오는 경우가 많습니다. 그래서 상태코드와 함께 응답 본문도 출력해 봅니다.

  4. 일일 API 호출 허용 횟수를 초과했을 때 수신하는 HTTP 상태 코드는?

    표준은 429(요청이 너무 많음)입니다. 공공데이터포털은 일일 한도를 넘으면 본문에 LIMITED_NUMBER_OF_SERVICE_REQUESTS_EXCEEDS_ERROR를 담아 알려 주기도 합니다.

  5. requests 응답 본문을 파이썬 딕셔너리로 역직렬화하는 메서드는?

    response.json() 메서드입니다. 서버가 반환한 JSON 문자열을 파이썬 객체로 즉시 변환합니다.

  6. macOS 터미널에서 API 서비스키를 임시 환경 변수로 등록하는 쉘 명령은?

    export DATA_GO_KR_API_KEY="인증키"를 실행하면 그 터미널 창에서만 유지되고, 파이썬에서는 os.environ.get("DATA_GO_KR_API_KEY")로 읽습니다. 계속 쓰려면 .env 파일에 두고 .gitignore에 등록합니다.
