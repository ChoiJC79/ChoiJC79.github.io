08. 공공데이터 연동과 보안 분리

공공데이터 API 인증키를 환경변수로 분리하여 보호하고 정적 웹페이지에 JSON 데이터를 안전하게 연결할 수 있다.

개념 읽기 → 실습 → 요점 카드 모두 「안다」 → 튜터와 대화로 다지기

왜 여기서 막히나

공공데이터 포털의 API를 사용하려고 HTML이나 자바스크립트 코드 안에 발급받은 인증키를 그대로 적는 실수가 자주 일어납니다. 이 상태로 GitHub Pages에 소스코드를 올리면 외부에 비밀키가 그대로 공개되어 계정이 정지되거나 보안 문제가 생깁니다. 정적 웹사이트는 방문자의 웹 브라우저에서 모든 코드가 실행되므로 비밀키를 숨길 수 있는 내부 저장 공간이 없습니다. 데이터 수집 단계와 화면 표시 단계를 명확히 분리하고 민감 정보를 보호하는 규칙을 익혀야 합니다.

핵심 개념 세 가지

  1. 환경변수와 .gitignore비밀 인증키나 비밀번호는 코드에 직접 적지 않고 .env 같은 별도 설정 파일에 환경변수로 저장합니다. git 저장소에 비밀 파일이 올라가지 않도록 .gitignore 파일에 .env 항목을 반드시 등록해야 합니다. 소스코드 저장소에는 비밀키 대신 변수 이름만 남기고 실제 값은 작업 컴퓨터 환경에만 보관합니다.
  2. 정적 사이트의 한계GitHub Pages는 서버가 없고 저장된 HTML, CSS, JS 파일을 방문자 브라우저로 그대로 보내주는 정적 웹 호스팅입니다. 따라서 자바스크립트 파일에 적힌 모든 문자열은 브라우저 개발자 도구를 통해 누구나 읽을 수 있습니다. 브라우저에서 비밀키를 직접 사용하는 방식은 정적 사이트에서 불가능하며 키가 필요 없는 공개 API를 쓰거나 별도 처리 과정이 필요합니다.
  3. 데이터와 화면의 분리웹 화면 코드 안에 긴 데이터를 하드코딩하지 않고 순수 데이터만 모아 data.json 파일로 따로 저장합니다. 화면 스크립트는 fetch 함수를 이용해 data.json을 읽어와서 화면의 목록이나 표 형태로 구성합니다. 이렇게 분리하면 데이터가 업데이트될 때 화면 코드를 건드리지 않고 JSON 파일만 교체할 수 있습니다.

같은 일, 다른 요청

이렇게 요청하면

공공데이터 포털에서 받은 버스 도착정보 API 키가 abc1234거든. index.html 파일 자바스크립트에 넣어서 우리 청사 앞 버스 시간 나오게 만들어줘.

이렇게 요청한다

공공데이터 API를 연동하려고 합니다. 보안 규칙을 엄격하게 지키면서 진행합니다.

[환경 및 보안 요구사항]
1. GitHub Pages를 사용 중이므로 클라이언트 브라우저 코드(JS)에 API 비밀키가 절대 노출되면 안 됩니다.
2. 파이썬 스크립트(scripts/fetch_data.py)를 만들어 외부 API 호출을 담당하게 합니다.
3. API 인증키는 .env 파일에서 SERVICE_KEY 환경변수로 읽어오도록 구현합니다.
4. .gitignore 파일에 .env가 등록되어 있는지 먼저 확인하고 누락되었다면 추가해 주십시오.

[데이터 출력 방식]
1. 파이썬 스크립트가 API에서 데이터를 가져와 가공한 뒤 data/bus.json 파일로 저장하게 만듭니다.
2. js/bus.js에서는 fetch('./data/bus.json')를 호출하여 화면의 테이블을 갱신하도록 구성합니다.

위 구조에 맞춰 필요한 파일 생성 순서와 파이썬 의존성 패키지를 안내해 주십시오.

비밀키가 웹 브라우저에 노출되는 위험을 원천 차단하고 파이썬 백엔드 스크립트와 환경변수로 격리했습니다. 데이터 갱신 결과물을 JSON 파일로 분리하여 정적 웹페이지에서도 안전하게 최신 정보를 표시할 수 있도록 설계했습니다.

30분 실습

  1. 프로젝트 루트에 .gitignore 파일을 열고 줄 끝에 .env를 적은 뒤 저장합니다.
  2. .env 파일에 TEST_KEY=12345 형태의 임시 환경변수를 만들고 git status로 추적 대상에서 제외되었는지 확인합니다.
  3. 기존 자바스크립트 파일에 하드코딩되어 있던 안내 공지사항 텍스트 목록을 data/notice.json 파일로 분리합니다.
  4. 자바스크립트에서 fetch를 사용해 notice.json 데이터를 불러와 화면에 목록으로 출력하도록 수정합니다.

통과 기준

  • git status 명령을 실행했을 때 .env 파일이 변경 목록에 나타나지 않습니다.
  • HTML 파일 안에서 실제 텍스트 내용이 제거되고 data/notice.json 파일에만 정돈되어 존재합니다.
  • GitHub 저장소 웹사이트에서 소스코드를 열어보았을 때 어떤 파일에도 실제 API 키가 적혀 있지 않습니다.

요점 카드

질문을 보고 답을 먼저 떠올린 뒤 눌러서 확인합니다. 답을 보지 않고 말할 수 있는 카드에만 「안다」를 표시하고, 모든 카드에 표시하면 이 단계를 통과합니다.

  1. 비밀 인증키를 git 추적 대상에서 제외하기 위해 등록하는 설정 파일명은?

    .gitignore입니다. 파일 안에 .env를 적어 두어야 커밋 과정에서 인증키 파일이 원격 저장소로 올라가지 않습니다.

  2. GitHub Pages 같은 정적 사이트에서 API 비밀키를 자바스크립트에 직접 적으면 안 되는 이유는?

    브라우저 개발자 도구나 소스 보기 창을 통해 누구나 자바스크립트 내부 문자열을 읽을 수 있기 때문입니다. 정적 호스팅 환경에서는 클라이언트 코드에 적힌 문자열을 숨길 수 없습니다.

  3. 정적 웹페이지에서 데이터를 HTML에 직접 쓰지 않고 분리할 때 사용하는 파일 형식과 호출 함수는?

    data.json 같은 JSON 파일로 분리하고 자바스크립트의 fetch() 함수로 불러옵니다. 데이터 내용이 바뀌어도 HTML 태그를 건드리지 않고 데이터 파일만 교체합니다.

  4. 공공데이터 포털에서 받은 XML 데이터를 브라우저에서 직접 다루기 어려울 때 처리하는 순서는?

    수집 파이썬 스크립트에서 XML을 JSON으로 변환하여 파일로 저장하고, 화면 스크립트에서는 변환된 JSON 파일을 읽어옵니다.

  5. Claude Code에게 API 연동 코드를 요청할 때 인증키를 다루는 안전한 방식은?

    대화창에 실제 인증키를 입력하지 않고 환경변수명만 지정하여 코드를 받습니다. 실제 키는 작업 컴퓨터의 .env 파일에 직접 기재합니다.

  6. 환경변수 파일이 git에 이미 커밋되어 히스토리에 남는 사고를 방지하기 위한 선행 작업은?

    .gitignore 파일에 .env를 추가하고 .gitignore를 먼저 커밋합니다. 한 번 커밋된 파일은 나중에 삭제 커밋을 올려도 이전 커밋 히스토리에 평문으로 남습니다.

튜터와 다지기

문제를 맞혔어도 내 프로젝트에서 바로 쓰지 못하면 아직 아는 것이 아닙니다. 아래 프롬프트를 Claude에 붙여 넣으면 「통과」라고 할 때까지 내 상황에 맞춘 질문을 계속 받습니다.

너는 내 바이브 코딩 튜터다. 나는 「공공데이터 연동과 보안 분리」 단계를 공부하고 있다.
이 단계의 목표는 「공공데이터 API 인증키를 환경변수로 분리하여 보호하고 정적 웹페이지에 JSON 데이터를 안전하게 연결할 수 있다.」
다룰 개념은 「환경변수와 .gitignore」, 「정적 사이트의 한계」, 「데이터와 화면의 분리」이다.

규칙
1. 설명부터 하지 말고, 내가 지금 만드는 프로젝트가 무엇인지 먼저 한 가지만 묻는다.
2. 질문은 한 번에 하나씩. 내 프로젝트 상황에 맞춘 문제를 낸다.
3. 내가 틀리면 정답을 바로 말하지 말고 힌트를 하나 준 뒤 다시 묻는다.
4. 개념마다 내가 실제로 보낼 프롬프트를 직접 써 보게 하고, 부족한 점을 고쳐 준다.
5. 서로 다른 상황 문제 세 개를 연속으로 맞히면 「통과」라고 말하고, 아직 약한 부분을 한 줄로 알려 준다.
6. 통과하기 전에는 다음 단계로 넘어가지 않는다.
