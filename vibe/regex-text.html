15. 정규표현식과 문서 텍스트 정제

주민등록번호와 전화번호 등 개인정보 패턴을 찾아 마스킹하고 공문서 접수일자 서식을 통일할 수 있다.

개념 읽기 → 실습 → 요점 카드 모두 「안다」 → 튜터와 대화로 다지기

왜 여기서 막히나

공문서나 민원 게시판 텍스트에는 주민등록번호, 연락처, 날짜가 제각각의 서식으로 섞여 있습니다. 정규표현식을 모르면 단순 글자 바꾸기로 수천 건의 문서를 일일이 수정하다가 오탈자를 남기거나 개인정보를 누락합니다. `re.findall`과 `re.sub`의 문법 구조를 알아야 AI에게 정밀한 마스킹 규칙을 지시할 수 있습니다. 에디터의 찾아 바꾸기 기능과 온라인 테스트 도구를 활용하면 대량의 보고서 원문을 손상하지 않고 안전하게 정제합니다.

핵심 개념 세 가지

  1. 메타문자와 패턴특정 규칙을 가진 문자열을 표현하기 위해 약속된 특수 기호 체계입니다. 숫자를 뜻하는 \d, 반복 횟수를 지정하는 {3,4}, 문자 범위를 나타내는 [0-9] 기호를 조합해 서식을 표현합니다. 예를 들어 휴대폰 번호는 \d{3}-\d{3,4}-\d{4} 패턴으로 일괄 탐색합니다.
  2. re.findall과 re.sub파이썬 내장 정규식 모듈에서 가장 널리 쓰이는 검색과 치환 함수입니다. re.findall() 함수는 본문에서 규칙에 맞는 모든 텍스트를 찾아 리스트로 반환합니다. re.sub() 함수는 패턴과 일치하는 부분을 마스킹 문자나 표준 날짜 서식 등 다른 문자열로 일괄 교체합니다.
  3. 정규식 검증과 VS Code 찾아 바꾸기작성한 패턴이 원하지 않는 텍스트까지 잘못 바꾸지 않는지 사전에 검토하는 절차입니다. regex101.com 사이트에서 실제 행정 문서 예시를 입력하고 매칭 여부를 미리 확인합니다. VS Code 편집기의 찾아 바꾸기 창에서 정규식 모드인 .* 버튼을 켜면 코드 작성 없이도 대량 문서의 서식을 즉시 바꿉니다.

자주 쓰는 코드

import re  # 정규표현식 처리를 위한 표준 모듈을 가져옵니다

text = '홍길동 850101-1234567 010-1234-5678 접수일: 2026.03.05'  # 정제 대상 민원 텍스트 예시입니다

rrn_pattern = r'(\d{6})-[1-4]\d{6}'  # 주민등록번호 앞자리와 뒷자리 패턴을 정의합니다
masked_text = re.sub(rrn_pattern, r'\g<1>-*******', text)  # 주민번호 뒷자리를 별표로 마스킹합니다

phone_pattern = r'01[016789]-\d{3,4}-\d{4}'  # 휴대전화번호 형식 패턴을 정의합니다
phone_list = re.findall(phone_pattern, masked_text)  # 텍스트에 포함된 전화번호를 모두 추출합니다

date_pattern = r'(\d{4})\.(\d{2})\.(\d{2})'  # 연.월.일 점 표기 날짜 패턴을 정의합니다
clean_text = re.sub(date_pattern, r'\1-\2-\3', masked_text)  # 연-월-일 하이픈 형식으로 통일합니다
print(clean_text)  # 마스킹과 서식 통일이 완료된 결과를 출력합니다

같은 일, 다른 요청

이렇게 요청하면

문서에 있는 주민번호 뒷자리 다 가려 주고 날짜도 형식 맞춰 줘.

이렇게 요청한다

파이썬 `re` 모듈의 `re.sub()` 함수를 사용해 민원 대장 텍스트를 정제하는 코드를 작성해 주십시오.
입력 텍스트에서 주민등록번호 패턴 `r'(\d{6})-[1-4]\d{6}'`을 찾아 뒷자리 7자리를 `*******`로 마스킹해야 합니다.
점 표기 날짜인 `r'(\d{4})\.(\d{2})\.(\d{2})'` 패턴은 `r'\1-\2-\3'` 하이픈 형식으로 변환해 주십시오.
코드를 적용하기 전 `regex101` 사이트에서 검증할 수 있는 테스트용 예시 문자열과 정규식 패턴도 각각 제시해 주십시오.

교체할 개인정보와 날짜의 구체적인 정규식 패턴 및 치환 형식을 명확히 전달하여 잘못된 마스킹 사고를 방지합니다. 사용할 함수를 `re.sub`로 지정하여 불필요한 반복문 생성을 막습니다. 사전 검증용 테스트 문자열을 함께 요구하여 안전하게 결과를 확인한 뒤 실무 문서에 적용하도록 돕습니다.

30분 실습

  1. 웹 브라우저로 regex101.com 사이트에 접속하여 테스트 언어를 파이썬으로 설정합니다.
  2. 테스트 문자열 창에 가상의 행정 민원 접수 내역 세 줄을 입력합니다.
  3. 정규식 입력창에 휴대폰 번호 패턴 01[016789]-\d{3,4}-\d{4}를 입력하여 일치 여부를 확인합니다.
  4. 파이썬 파일에서 re.sub 함수를 실행하여 주민등록번호 뒷자리가 *******로 교체된 결과를 터미널에서 확인합니다.

통과 기준

  • regex101 화면 우측 매칭 정보에 입력한 전화번호 세 건이 정확히 탐지되어 표시됩니다.
  • 파이썬 스크립트 실행 결과 화면에서 주민등록번호 뒷자리 7자리가 별표로 마스킹되어 나타납니다.
  • 점 표기로 되어 있던 접수일자가 모두 하이픈 형태인 YYYY-MM-DD 형식으로 통일되어 출력됩니다.

요점 카드

질문을 보고 답을 먼저 떠올린 뒤 눌러서 확인합니다. 답을 보지 않고 말할 수 있는 카드에만 「안다」를 표시하고, 모든 카드에 표시하면 이 단계를 통과합니다.

  1. 정규표현식에서 임의의 한 자리 숫자를 나타내는 메타문자는?

    \d 메타문자를 사용합니다.

  2. 파이썬 re 모듈에서 정규식 패턴과 일치하는 텍스트를 다른 문자열로 일괄 치환하는 함수는?

    re.sub() 함수를 사용합니다.

  3. 주민등록번호 뒷자리 7자리를 찾는 정규식 패턴 구문은?

    [1-4]\d{6}입니다. 첫 자리가 성별·출생 세기 숫자(1~4)이고 뒤 6자리가 숫자라는 뜻입니다. 외국인등록번호까지 잡으려면 [1-8]로 넓힙니다.

  4. 일반 휴대전화 식별 번호 세 자리를 검출하는 정규식 패턴은?

    01[016789] 패턴을 사용합니다.

  5. 정규표현식 패턴을 실제 텍스트에 적용하기 전에 미리 시뮬레이션하고 테스트할 수 있는 웹사이트 주소는?

    regex101.com 사이트를 이용합니다.

  6. VS Code 에디터의 찾기 및 바꾸기 창에서 정규표현식 검색을 활성화하는 단축 아이콘 모양은?

    마침표와 별표가 그려진 .* 아이콘을 클릭합니다.

튜터와 다지기

문제를 맞혔어도 내 프로젝트에서 바로 쓰지 못하면 아직 아는 것이 아닙니다. 아래 프롬프트를 Claude에 붙여 넣으면 「통과」라고 할 때까지 내 상황에 맞춘 질문을 계속 받습니다.

너는 내 바이브 코딩 튜터다. 나는 「정규표현식과 문서 텍스트 정제」 단계를 공부하고 있다.
이 단계의 목표는 「주민등록번호와 전화번호 등 개인정보 패턴을 찾아 마스킹하고 공문서 접수일자 서식을 통일할 수 있다.」
다룰 개념은 「메타문자와 패턴」, 「re.findall과 re.sub」, 「정규식 검증과 VS Code 찾아 바꾸기」이다.

규칙
1. 설명부터 하지 말고, 내가 지금 만드는 프로젝트가 무엇인지 먼저 한 가지만 묻는다.

5. 서로 다른 상황 문제 세 개를 연속으로 맞히면 「통과」라고 말하고, 아직 약한 부분을 한 줄로 알려 준다.
