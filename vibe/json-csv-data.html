16. json과 csv 모듈로 데이터 변환하기

공공데이터 포털의 CSV 파일을 웹용 JSON으로 변환하고 엑셀 한글 깨짐을 해결할 수 있다.

개념 읽기 → 실습 → 요점 카드 모두 「안다」 → 튜터와 대화로 다지기

왜 여기서 막히나

공공데이터 포털이나 행정시스템에서 내려받은 자료는 대부분 CSV 형식입니다. 그러나 GitHub Pages로 운영하는 웹페이지는 자바스크립트의 `fetch` 함수를 사용하여 JSON 형식 데이터를 읽어옵니다. 데이터 형식을 모르면 AI에게 웹용 데이터를 만들어 달라고 요청할 때 의도하지 않은 구조가 생성되거나 한글이 깨집니다. 두 형식의 구조 차이와 인코딩 방식을 이해하면 Claude Code에게 명확한 변환 스크립트를 요청할 수 있습니다.

핵심 개념 세 가지

  1. CSV와 JSON의 구조 차이CSV는 쉼표로 열을 나누는 2차원 표 형식 데이터입니다. JSON은 중괄호와 대괄호로 계층 구조와 목록을 표현하는 웹 표준 데이터 형식입니다. 표 형태 행정 문서는 CSV가 다루기 쉽고 웹 화면 목록 표시는 JSON이 적합합니다.
  2. 엑셀 한글 깨짐과 utf-8-sigmacOS나 리눅스 환경에서 생성한 UTF-8 CSV 파일은 윈도우 엑셀에서 열 때 한글이 깨집니다. 엑셀 프로그램이 파일 시작 부분의 바이트 순서 표식인 BOM을 요구하기 때문입니다. 파이썬에서 파일 인코딩을 utf-8-sig로 지정하면 윈도우 엑셀에서도 한글이 정상 출력됩니다.
  3. 웹페이지의 fetch 동작 원리웹 브라우저는 fetch('data.json') 명령으로 서버에 위치한 JSON 파일을 비동기로 가져옵니다. 브라우저 자바스크립트는 수신한 JSON 텍스트를 response.json() 함수로 자바스크립트 객체 배열로 변환합니다. 웹페이지에 행정 목록을 표시하려면 표 데이터를 이 형식으로 변환해 두어야 합니다.

자주 쓰는 코드

import csv, json  # 표준 라이브러리인 csv와 json 모듈을 불러옵니다
with open('data.csv', encoding='utf-8-sig') as f:  # 엑셀 호환 인코딩으로 CSV 파일을 엽니다
    rows = list(csv.DictReader(f))  # 첫 줄 헤더를 키로 삼아 딕셔너리 목록을 만듭니다
with open('data.json', 'w', encoding='utf-8') as f:  # 웹에서 쓸 JSON 파일을 엽니다
    json.dump(rows, f, ensure_ascii=False, indent=2)  # 한글을 보존하고 들여쓰기 2칸으로 저장합니다

같은 일, 다른 요청

이렇게 요청하면

공공데이터에서 다운받은 엑셀 파일 웹사이트에 띄우게 코딩해 줘.

이렇게 요청한다

다운로드 폴더의 `complaints.csv` 파일을 읽어서 웹용 `complaints.json`으로 변환하는 파이썬 스크립트를 작성해 주십시오.
파이썬 기본 `csv.DictReader`와 `json.dump`를 사용하고 한글이 유니코드 기호로 바뀌지 않도록 `ensure_ascii=False` 옵션을 지정해 주십시오.
변환 후 생성된 `complaints.json` 파일의 첫 번째 객체 키와 값을 터미널에 3줄 출력하여 검증하는 코드도 포함해 주십시오.

`good` 요청은 사용할 파이썬 내장 모듈과 입출력 파일명을 명확하게 지정합니다. 또한 `ensure_ascii=False` 옵션을 명시하여 한글 깨짐을 방지하고 터미널 검증 출력까지 요구합니다. Claude Code가 불필요한 외부 라이브러리 설치 없이 즉시 실행 가능한 검증 코드를 생성하게 만듭니다.

30분 실습

  1. 공공데이터포털에서 주민센터 민원 현황 CSV 파일을 내려받아 작업 폴더에 input.csv로 저장합니다.
  2. 터미널에서 파이썬 스크립트를 작성하여 input.csv를 읽고 utf-8-sig 인코딩을 적용해 excel_view.csv로 다시 저장합니다.
  3. 같은 데이터를 json.dump 함수를 사용하여 ensure_ascii=False, indent=2 옵션으로 web_data.json 파일로 변환합니다.
  4. 터미널에서 head -n 20 web_data.json 명령을 실행하여 첫 번째 항목의 한글과 괄호 구조를 직접 확인합니다.

통과 기준

  • 엑셀 프로그램에서 excel_view.csv를 열었을 때 민원명과 부서명 한글이 깨지지 않고 표 형식으로 열립니다.
  • web_data.json 파일 크기가 0바이트가 아니며 첫 글자가 대괄호 [로 시작하고 마지막 글자가 ]로 끝납니다.
  • 터미널에서 cat web_data.json 명령을 실행했을 때 유니코드 이스케이프 기호가 아니라 완성형 한글이 표시됩니다.

요점 카드

질문을 보고 답을 먼저 떠올린 뒤 눌러서 확인합니다. 답을 보지 않고 말할 수 있는 카드에만 「안다」를 표시하고, 모든 카드에 표시하면 이 단계를 통과합니다.

  1. 윈도우 엑셀에서 UTF-8 CSV 파일의 한글 깨짐을 방지하는 파이썬 인코딩 이름은?

    utf-8-sig입니다. 파일 시작 부분에 UTF-8 바이트 순서 표식인 3바이트 BOM을 기록하여 엑셀이 인코딩을 인식하도록 돕습니다.

  2. CSV 파일의 첫 줄 머리글을 키로 활용해 각 행을 딕셔너리로 읽어오는 파이썬 클래스는?

    csv.DictReader입니다. list(csv.DictReader(f)) 형태로 호출하면 머리글 이름을 키로 갖는 딕셔너리 목록이 생성됩니다.

  3. 파이썬 json.dump에서 한글 문자가 아스키 형태의 유니코드 기호로 바뀌는 현상을 방지하는 옵션은?

    ensure_ascii=False입니다. 이 옵션을 지정해야 원본 한글 문자 그대로 JSON 파일에 저장됩니다.

  4. 웹 브라우저 자바스크립트에서 외부 data.json 파일을 비동기로 가져오는 기본 함수는?

    fetch 함수입니다. fetch('data.json').then(response => response.json()) 구문으로 데이터를 수신하여 화면에 표시합니다.

  5. JSON 파일이 사람이 읽기 편하도록 2칸 들여쓰기를 적용하는 json.dump 매개변수는?

    indent=2입니다. 이 매개변수를 생략하면 줄바꿈 없이 한 줄로 압축 저장됩니다.

  6. macOS 터미널에서 생성된 JSON 파일 내용의 앞부분 10줄을 확인하는 명령어는?

    head -n 10 파일명.json입니다. 대용량 파일 전체를 열지 않고도 구조와 한글 정상 출력 여부를 즉시 검증할 수 있습니다.
