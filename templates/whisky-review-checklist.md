# 위스키 리뷰 페이지 신규 등록 체크리스트

새 위스키 1종을 사이트에 추가할 때마다 이 파일을 복사해 진행 상황을 체크한다.

## 준비
- [ ] 대상 위스키: {{한글명}} {{연산}}년산 / 슬러그: `{{슬러그}}.html`
- [ ] 참고 자료(공식 사이트, 리뷰, 테이스팅 노트 출처) 확보

## 페이지 작성
- [ ] `templates/whisky-review.html`을 루트에 `{{슬러그}}.html`로 복사
- [ ] `{{ }}` 플레이스홀더 전부 치환 (누락 없는지 `grep -n "{{" {{슬러그}}.html`로 확인)
- [ ] OG 메타태그(`og:title`, `og:description`, `og:url`) 값 확인
- [ ] 타임라인·제품 라인업·테이스팅 노트 카드 수는 필요에 따라 늘리거나 줄여도 됨 (구조는 유지)

## 목록 페이지 등록
- [ ] `whisky.html`의 `.col-card` 목록에 새 카드 추가 (썸네일 이미지 경로 `/img/col_{{슬러그}}.jpg` 포함)
- [ ] 썸네일 이미지를 `img/` 폴더에 추가

## 배포
- [ ] `publish.py`의 `main()` 함수에 `push_local("{{슬러그}}.html", "add {{한글명}} guide")` 호출 추가 (신규 파일은 반드시 추가해야 배포됨)
- [ ] `🚀 사이트에 올리기.bat` 실행
- [ ] 배포 후 `https://choijc79.github.io/{{슬러그}}.html` 접속 확인
